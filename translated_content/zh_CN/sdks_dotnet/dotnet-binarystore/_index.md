Dapr Binary Store 包让 .NET 应用程序能够在已配置的 Dapr Binary Store component 中存储、检索、流式传输和删除二进制文件。它支持基于流的上传和下载，适用于大文件；也支持对可以放入内存的文件进行字节数组访问。源生成器还可以创建绑定到特定 Binary Store 的类型化客户端。

要开始使用，请参阅 [Dapr Binary Store 操作指南]({{% ref dotnet-binarystore-howto.md %}})，并参考 [客户端用法指南]({{% ref dotnet-binarystore-client-usage.md %}})，了解配置、流式处理和错误处理。
