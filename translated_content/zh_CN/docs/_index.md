## Dapr，分布式应用运行时

Dapr 为通信、状态、工作流和智能体 AI 提供 API。这些 API 将应用代码与底层基础设施解耦，确保灵活性和可移植性。Dapr 利用业界在安全性、弹性和可观测性方面的最佳实践，让您可以专注于自己的代码。
