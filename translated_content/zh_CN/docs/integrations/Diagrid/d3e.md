[Diagrid Dapr Distribution for Enterprise (D3E)](https://docs.diagrid.io/dapr-open-source/d3e) 是开源 Dapr 项目的定制发行版，它为 Dapr 增加了额外的安全和可扩展性能力，同时与 Dapr API 和 SDK 保持完全兼容。它专为大规模生产环境设计，面向对安全有严格要求或部署了大量 Dapr 的组织。

**多租户支持**

在同一环境中跨多个租户运行 Dapr，适用于大规模部署。

**减少安全权限**

运行所需的权限范围比开源 Dapr 更窄，适用于对安全有严格要求的组织。

**企业级支持**

提供企业支持，保证响应时间，并将 CVE 修复回溯到定制版本。

**完全的 API 兼容性**

与 Dapr API 和 SDK 保持完全兼容，现有应用无需修改即可运行。
