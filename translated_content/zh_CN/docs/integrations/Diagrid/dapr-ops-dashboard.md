[Dapr Ops Dashboard](https://www.diagrid.io/dapr-ops-dashboard)（原名 Diagrid Conductor）是一款免费的 SaaS 工具，可在你的 Kubernetes 集群中自动化并管理 Dapr 部署。从开发到生产，它带来卓越的运维、安全性与可靠性，以及洞察力。

**自动化运维**

一键安装、带自动回滚的升级、零停机的 mTLS 证书轮换和配置同步，让所有集群中的 Dapr 保持最新。通过定时更新与金丝雀更新，实现零停机。

**Advisor：发现并应用最佳实践**

针对 50+ 项生产标准进行持续检查，在问题进入生产环境之前发现安全配置错误和优化机会。

**深度可观测性**

150+ 项指标、20+ 个内置仪表板、组件健康检查、Actor 指标，以及动态的应用图谱，可视化你的服务与基础设施组件。你还可以通过指标 API 将指标导出到 Grafana。

**告警与通知**

自定义告警，支持电子邮件和 Webhook 通知，让你的团队在问题影响用户之前及时响应。

**多集群管理与安全**

通过单一 Web 控制台管理多个集群，支持集群级别的 RBAC、审计日志，以及用于 GitOps 自动化的 Kubernetes Operator。

**资源用量报告**

基于过往的资源使用情况给出推荐，显著节省 CPU 与内存成本。

**可运行于任何 Kubernetes**

支持托管 Kubernetes（AKS、EKS、GKE）、本地部署发行版（OpenShift、Rancher、原生 Kubernetes），以及本地集群（Kind、Minikube、Docker Desktop）。
