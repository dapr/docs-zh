Dapr 通过一个扩展与 [Azure Functions 运行时](https://learn.microsoft.com/azure/azure-functions/functions-overview) 集成，该扩展让函数能够与 Dapr 无缝交互。
- **Azure Functions** 提供事件驱动的编程模型。
- **Dapr** 提供云原生的构建块。

该扩展将两者结合，适用于无服务器和事件驱动的应用。
