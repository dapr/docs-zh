对于在生产环境中运行 Dapr、需要企业级支持、服务级别协议（SLA）、认证发行版或完全托管服务的组织，Dapr 生态系统提供商业服务。以下服务由 [Diagrid](https://www.diagrid.io/) 提供，它是 Dapr 项目的主要贡献者之一。

## Dapr 开源支持

Diagrid 为任何云上的开源 Dapr 提供 [Dapr Support](https://www.diagrid.io/dapr-support)，分为两个方案。Dapr Support Pro 面向开发阶段的团队，每月 99 美元，提供不限数量的邮件工单，以及美国和欧盟工作时间的支持覆盖，性价比高。Enterprise Dapr Support 面向关键的生产环境，提供 24x7 支持，关键问题一小时内响应，部署方案价格另议。

## Diagrid

[Diagrid]({{< ref diagrid-platform.md >}}) 是一个构建在 Dapr 之上的持久执行平台，让 AI 代理和 workflow 具备持久性、可验证性与安全性。

{{< button text="了解 Diagrid" page="diagrid-platform.md" >}}

## Diagrid Dapr Distribution for Enterprise (D3E)

[D3E]({{< ref d3e.md >}}) 是开源 Dapr 项目的定制发行版，在与 Dapr API 和 SDK 保持完全兼容的同时，增加了额外的安全与可扩展性能力。它专为大规模生产环境设计，提供多租户支持、更小的安全权限集、带有保证响应时间的企业支持，并为定制版本回移 CVE 修复。它面向对安全有严格要求或部署了大量 Dapr 的组织。

{{< button text="了解 D3E" page="d3e.md" >}}

## Diagrid Dapr Ops Dashboard

免费的 [Dapr Ops Dashboard]({{< ref dapr-ops-dashboard.md >}}) 为 Kubernetes 上的 Dapr 提供运维与 observability 自动化，支持一键安装和升级、自动化的最佳实践检查，并提供跨所有集群的应用图谱。
