[Azure Container Apps](https://docs.microsoft.com/azure/container-apps/overview) 是一个无服务器应用程序托管服务，用户无需查看或管理任何底层虚拟机、编排器或其他云基础设施。Azure Container Apps 使您能够运行打包在多个容器中的应用程序代码，并且对所使用的运行时或编程模型没有任何偏好。


Dapr 内置于 Container Apps 中，使您能够使用 Dapr API 构建块，而无需手动部署 Dapr 运行时。您只需部署服务及其 Dapr 组件即可。
