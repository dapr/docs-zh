Dapr Agents 支持在 `DurableAgent` 推理循环中将其他 Agent 作为工具调用，包括来自其他框架的 Agent（如 OpenAI Agents、LangGraph 和 CrewAI）。

有关完整文档和代码示例，请参阅 [将 Agent 作为工具]({{% ref "dapr-agents-core-concepts.md#agents-as-tools" %}})。
