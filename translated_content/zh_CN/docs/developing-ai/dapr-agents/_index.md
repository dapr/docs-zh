###  什么是 Dapr Agents？

Dapr Agents 是一个 Python 框架，用于利用 Dapr 的分布式系统能力构建由 LLM 驱动的自主 Agent 应用。它提供工具来创建能够执行持久任务、做决策并通过工作流协作的 AI Agent，同时利用 Dapr 的状态管理、消息传递和可观测性特性来实现大规模可靠执行。
