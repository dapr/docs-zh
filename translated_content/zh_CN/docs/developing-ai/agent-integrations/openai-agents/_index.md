### Dapr OpenAI Agents 集成是什么？

Dapr 提供了 OpenAI agents 的一等集成，范围涵盖从 agent 会话管理到通过发布订阅连接 agents 以及编排 agentic 工作流。Dapr OpenAI 集成是 OpenAI Python SDK 中的一个扩展，开发者可以使用它通过各种 Dapr API 来增强 OpenAI agents。
