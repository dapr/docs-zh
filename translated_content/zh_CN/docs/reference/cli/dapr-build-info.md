### 说明

获取 `dapr` 和 `daprd` 可执行文件的版本和 git 提交数据。

### 支持的平台

- [Self-Hosted]({{% ref self-hosted %}})

### 用法

```bash
dapr build-info
```

### 相关说明

您可以通过调用 `daprd --build-info` 命令直接获取 `daprd` 构建信息。
